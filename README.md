# 🏰 DungeonXplorer — Application « Livre dont vous êtes le Héros »

**Projet de groupe (5–6 étudiants)**  
**Technos : PHP • MySQL • JavaScript • HTML • CSS • MVC • PDO • Bootstrap**

DungeonXplorer est une application web permettant à une communauté de joueurs de vivre une aventure interactive de type *Livre dont vous êtes le héros*.  
Le projet est développé pour l’association **Les Aventuriers du Val Perdu**.

---

## 📌 Objectifs pédagogiques  
- Traiter un formulaire HTML avec PHP  
- Concevoir et réaliser une base de données MySQL  
- Implémenter un **CRUD** complet  
- Communiquer avec la base via **PDO**  
- Utiliser le **design pattern MVC**  
- Concevoir / intégrer un **mini-framework PHP**  
- Versionner le projet via **Git + GitHub**

---

## 🎯 Fonctionnalités — Version 1

### 👤 Joueur
- Création de compte  
- Connexion / déconnexion  
- Création d’un personnage (Guerrier • Voleur • Magicien)  
- Démarrage ou reprise de l’aventure  
- Page de profil (caractéristiques, inventaire, progression…)  
- Suppression du compte

### 🛡️ Administrateur
- Toutes les fonctionnalités du joueur  
- Gestion des comptes joueurs  
- Gestion des contenus :
  - Chapitres  
  - Monstres  
  - Trésors  
  - Images / médias

---

## 🔮 Version 2 — Évolutions envisagées
